# Pallier1-U1-L1

Standalone version of the French Practice Hub lesson.

## Run locally

Open `index.html` with VS Code Live Server. The lesson's images are embedded in
`script.js`; Google Fonts and any configured videos require an internet connection.

## Files

- `index.html` contains the lesson structure.
- `style.css` contains its styles and responsive layouts.
- `script.js` contains the lesson content, interactions, and game logic.
- `FPH-Lecon1-ELEVES-verrouille-WordPress.html` is the unchanged original source.
